# Cognisphere — V2 Beta

A collection of elegant cognitive mini-games that estimate your mental profile across 9 active dimensions — probabilistically, playfully, progressively.

## Live Demo
[cognisphere-v1.netlify.app](https://cognisphere-v1.netlify.app)

## Features
- 9 cognitive mini-games (Logic Bridge, Symbol Sprint, Memory Stack, Pattern Triangles, Reality Rank, Iceberg Inference, Verbal Analogy, Number Sequence, Rule Shift)
- 9 active cognitive domains
- Bilingual EN / FR
- Dark / Light mode
- PWA — saveable to iPhone home screen
- 100% local data — nothing transmitted
- Radar chart · PDF & JSON export

## Tech
Single-file HTML · CSS · Vanilla JS · Chart.js · jsPDF · No framework · No build step

## Deploy
Drag the folder onto [app.netlify.com/drop](https://app.netlify.com/drop)
